# Data card

All 55 documents and 52 queries in this repository are fictional benchmark fixtures. There are 47 active and eight superseded documents. The 18-question development split has 12 answerable and six unanswerable queries; the 34-question test split has 24 answerable and ten unanswerable queries. Each answerable query has one labelled gold evidence document ID.

No patient data, real employee information, real organizational policies, personal records or external copyrighted corpora are included. The benchmark is intentionally small and lexically simple, so scores do not estimate real-world RAG performance.
